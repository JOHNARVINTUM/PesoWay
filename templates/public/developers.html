PesoWay developer docs

Build a test payment flow.

Use PesoWay’s versioned REST API to create a payment intent, send a customer to a hosted checkout, and observe the result through the ledger and signed webhooks.

Simulation only. PesoWay does not transfer real funds or accept live wallet, OTP, PIN, or card data.

Quickstart

  1. Create a merchant application and scoped API key.
  2. Create a payment intent with an idempotency key.
  3. Open the returned checkout URL.
  4. Complete a controlled simulation and receive events.
POST /api/v1/payment-intents/
Authorization: Bearer pw_…
Idempotency-Key: order-1001-create

{
  "amount_centavos": 12500,
  "currency": "PHP",
  "merchant_reference": "order-1001",
  "return_url": "https://merchant.example/complete"
}

Test mode

Use the local Payment Flight Deck to exercise all supported simulation paths. The hosted checkout is available only in Django debug mode and always carries a visible simulation label.

Payment intents

POST/api/v1/payment-intents/

Create a PHP payment intent. Requires payments:write.

GET/api/v1/payment-intents/{id}/

Retrieve an intent owned by the authenticated merchant. Requires payments:read.

POST/api/v1/payment-intents/{id}/cancel/

Cancel an eligible nonterminal intent. Requires payments:write.

Hosted checkout

Open /checkout/{payment-intent-id}/. On a successful test payment, PesoWay redirects to the intent’s validated return_url and adds payment_intent plus status=succeeded.

Webhooks

Register an HTTPS endpoint with webhooks:write. Every payload is signed with HMAC-SHA256 and includes an event ID and timestamp. Validate the raw body, reject stale timestamps, and store event IDs idempotently.

Security model

  • API keys are hashed at rest and returned only at creation.
  • All resource queries are merchant scoped.
  • Amounts are integer centavos; no floating-point money values are accepted.
  • Idempotency keys, database transactions, row locking, and immutable ledger entries protect workflow integrity.
  • Test-only checkout and simulation routes disappear when debug mode is disabled.
